## How To Run
1. Download this repository
2. Run "npm install"
3. Run "mkdir tmp" (if needed)
4. Make the .env file, use the .env.example as starting point
5. Run "node ace migration:run --force"
6. Run "node ace db:seed"
7. Run "npm run dev" to start development server
